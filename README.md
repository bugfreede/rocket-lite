# RocketLite

A lightweight Shadowrocket-style proxy client for Android.

- Clean Material 3 UI built with Jetpack Compose
- Import nodes from share links: `ss://`, `vmess://`, `vless://`, `trojan://`
- Subscription import (base64 node lists)
- VpnService-based tunnel architecture
- Proxy core: sing-box (libbox AAR), integrated in phase 2

Status: phase 1 — UI, node parsing and storage, VPN service skeleton.
